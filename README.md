# Zanchetin Digital

Crie um site profissional, premium, moderno e totalmente responsivo para a marca Zanchetin Technology, focada em desenvolvimento de sites, sistemas web e soluções digitais para empresas. O responsável pela marca é Nicolas Zanchetin, Desenvolvedor de Software e estudante de Análise e Desenvolvimento de Sistemas, com conhecimentos em Java, Spring Boot, React, TypeScript, bancos de dados e sistemas empresariais.

OBJETIVO DO SITE
- Passar credibilidade para potenciais clientes.
- Apresentar serviços de desenvolvimento.
- Mostrar projetos e portfólio.
- Gerar pedidos de orçamento pelo WhatsApp.
- Construir uma imagem profissional para a marca Zanchetin Technology.
- Servir como cartão de visitas digital e demonstração da qualidade dos trabalhos.

POSICIONAMENTO
Nome principal: Zanchetin Technology
Profissional responsável: Nicolas Zanchetin
Subtítulo possível: “Software • Web • Tecnologia” ou “Soluções digitais para empresas que querem evoluir.”
Não apresente como grande empresa ou equipe. Apresente como marca independente de desenvolvimento de software e soluções digitais liderada por Nicolas Zanchetin. Não invente funcionários, clientes, prêmios, escritório físico, avaliações ou números.

ESTILO VISUAL
Visual de software house moderna, startup premium e consultoria tecnológica. Deve transmitir tecnologia, confiança, modernidade, profissionalismo e qualidade. Evite aparência de portfólio de estudante e efeitos exagerados.

SERVIÇOS
Seção “Soluções digitais para o seu negócio” com cards modernos:
1. Sites Institucionais — design profissional, responsividade, WhatsApp, formulários, SEO básico, Google Maps, domínio/publicação, performance. CTA “Quero um site profissional”.
2. Landing Pages — layout estratégico, CTAs, formulários, WhatsApp, alta performance, mobile-first.
3. Sistemas Web — estoque, pedidos, clientes, produção, logística, orçamentos, controle administrativo, dashboards.
4. Sistemas Empresariais — ERP, CRM, gestão de estoque, produção, usuários, relatórios e dashboards.
5. Manutenção e Evolução — correções, conteúdo, novas funcionalidades, UI e otimização.

DIFERENCIAL
Seção escura com título “Não é apenas um site. É uma ferramenta para o seu negócio.”
Texto sobre soluções desenvolvidas conforme os objetivos e necessidades da empresa, evitando templates genéricos.
Destaques: Design personalizado, Responsivo, Performance, Evolução.

PORTFÓLIO
Seção “Projetos” com imagem/mockup, nome, categoria, descrição, tecnologias, botão “Ver projeto” e “Detalhes”.
Projeto 1: ERP para Esquadrias de Alumínio — Sistema Empresarial / SaaS. Descrição: sistema para centralizar processos de empresas de esquadrias de alumínio, conectando gestão, usuários, estoque, projetos e operações. Tecnologias: Java, Spring Boot, React, PostgreSQL, Docker. Recursos: usuários, controle de acesso, dashboard, multiempresa, gestão de projetos, estoque, produção, auditoria, segurança. Selo “Projeto em desenvolvimento”.
Projeto 2: Sistema de Controle de Estoque de Alumínio — Sistema Empresarial. Aplicação para controle de perfis, movimentações, sobras, endereçamento e histórico. Tecnologias: Java, JavaFX, SQL. Recursos: cadastro de materiais, entrada/saída, sobras, endereçamento, histórico, usuários.
Projeto 3: Website para Escritório de Advocacia — Website Institucional. Marcar claramente “Projeto conceitual”. Descrição: site profissional focado em credibilidade, elegância, apresentação dos serviços e geração de contatos. Tecnologias: React, TypeScript, Tailwind CSS.
Deixe estrutura preparada para novos projetos, aceitando screenshot, nome, descrição, tecnologias, categoria, status, URL e GitHub opcional.

04 Revisão — apresentação e ajustes.
05 Publicação — domínio e disponibilização.
06 Suporte — manutenção e evolução.

Profissional — A partir de R$ 1.500 — destacar “Mais escolhido” — site institucional profissional, design personalizado, múltiplas seções, responsividade, WhatsApp, formulário, SEO, Google Maps e publicação.
Personalizado — Sob orçamento — sistemas, aplicações, dashboards, automações, ERP e soluções específicas.

INTERAÇÕES
Fade-in, animações no scroll, hover nos cards, transições suaves, glow azul discreto e efeitos leves de profundidade. Tudo rápido e sem exageros.

RESPONSIVIDADE
Mobile-first e impecável em smartphones, iPhone, Android, tablets, notebooks, Full HD e ultrawide. Sem overflow horizontal, textos cortados ou cards quebrados.

SEO
Title: “Zanchetin Technology | Desenvolvimento de Sites e Sistemas”.
Meta description: “Desenvolvimento de sites profissionais, sistemas web e soluções digitais personalizadas para empresas. Zanchetin Technology — Dourados, MS.”
Preparar H1/H2/H3, meta tags, Open Graph, sitemap, robots.txt e canonical. Palavras-chave: criação de sites Dourados, desenvolvedor de sites Dourados, criação de sites Mato Grosso do Sul, desenvolvimento de sistemas, sistema personalizado para empresas, desenvolvimento de software, criação de landing pages, sistema de estoque, sistemas empresariais.

PERFORMANCE
Buscar excelente Lighthouse: lazy loading, imagens otimizadas, reduzir JS desnecessário, Core Web Vitals, acessibilidade, SEO e boas práticas.

LGPD
Criar Política de Privacidade, Termos de Uso e consentimento no formulário. Só usar banner de cookies se realmente houver cookies não essenciais.

TECNOLOGIA/ARQUITETURA
Use React + TypeScript + Tailwind + Vite, componentes reutilizáveis e arquitetura organizada. Pode usar Lucide Icons, shadcn/ui e Framer Motion quando fizer sentido. Centralize configurações de nome, telefone, WhatsApp, e-mail, redes sociais, projetos, serviços, preços e tecnologias. Componentes sugeridos: Header, Hero, Services, Portfolio, ProjectCard, Process, About, Technologies, Pricing, CTA, Contact, Footer, WhatsAppButton.

PORTFÓLIO COM MOCKUPS
Apresente projetos com mockups de notebook, monitor e smartphone. Ao clicar em um projeto, abra página ou modal com problema, solução, funcionalidades, tecnologias, screenshots e status.

IMPORTANTE
Não invente clientes, avaliações, depoimentos, anos de experiência, número de projetos, faturamento, parceiros, grandes empresas, certificados, equipe ou endereço físico. Caso não existam clientes reais, use “Projetos” ou “Projetos conceituais”, nunca “Clientes atendidos”. O objetivo é que um empresário entre no site e pense: “Esse profissional consegue criar algo desse nível para minha empresa.” O próprio site deve ser a melhor demonstração da qualidade oferecida.
